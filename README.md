# Resources

Research and desk library for the crypto agent book.

**Purpose:** Cache insights here so Grok Bot does not re-burn usage on the same research.

## Layout

- `desk/` — trading rules, rails, post-mortems
- `markets/` — reusable market notes (majors, memes, catalysts)
- `playbooks/` — how we enter, trail, and exit

## Usage rule (for agents)

1. Read this repo first for any research ask.
2. Write new findings back as markdown.
3. Only call live research connectors when the answer is missing or clearly stale.
